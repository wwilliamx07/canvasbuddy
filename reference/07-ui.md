# 07 — UI

Sources: `src/App.tsx` (state owner), `src/components/{Navigation,ChatUI,Settings,GraphExplorer}`, `src/index.css`, `src/App.css`.

## Component tree and state ownership

```
<App>                         owns: activeTab, chats[], currentChatId, messages, contextDigests,
 │                                  isLoading, settings, currentContextTokens
 ├── <Navigation>             left rail (w-48): Chat / Graph / Settings tabs; chat list with
 │                            new/select/delete (only rendered on the Chat tab)
 └── <main>
      ├── <ChatUI>            messages + input; props only, no state beyond the input box
      ├── <GraphExplorer>     self-contained: loads its own data from db/* and canvas/sync
      └── <Settings>          controlled form; auto-saves every change via onSettingsChange
```

`App` is the single owner of chat and settings state and is the only place that writes `localStorage`. `GraphExplorer` is the exception to "props down": it reads and writes the database directly because it is a debugging/administration surface over the same data layer the agent uses.

Tabs are mutually exclusive (`activeTab === 'x' && …`), so switching away from the Graph tab unmounts the explorer and its in-memory state (selected course, collapsed modules); switching back reloads from PGlite.

## ChatUI

- Renders user bubbles as plain text and assistant bubbles as Markdown via `marked` into `dangerouslySetInnerHTML` (no sanitizer; extension CSP blocks inline script).
- Auto-scrolls to the newest message. Input is disabled while `isLoading`.
- Tool activity is not visualised; the user sees only assistant text, including any interim text the model emits between tool rounds. Chats are titled from their first message.
- Styling: light theme (`bg-gray-50`), Tailwind `prose` classes for Markdown, word-break rules so long tokens don't overflow the narrow side panel.

## Settings

`AppSettings` (exported from `Settings.tsx`, used everywhere):

```ts
{ apiKey, baseUrl, model, embeddingModel?, llmProvider: 'openai' | 'google', contextThreshold, freshness? }
```

- Every field auto-saves on change; "Cancel" only resets the local form to the last saved value.
- `baseUrl` is only used by the OpenAI adapter (chat and embeddings), enabling OpenAI-compatible providers.
- Shows the live context estimate against the threshold (see `02-agent-loop.md` for what the estimate excludes).
- Defaults live in `src/settings.ts` (`DEFAULT_SETTINGS`, `normalizeSettings`): provider `google`, model `gemini-3.1-flash-lite-preview`, embedding `gemini-embedding-2`, threshold 15,000, `freshness` = `DEFAULT_FRESHNESS`.
- **Freshness section**: one numeric (minutes) field per collection plus probe debounce and unavailable-retry, with a reset-to-defaults button. Writes `settings.freshness`; the engine reads it on every `ensureCollection` call, so changes apply immediately.

## Graph Explorer

A dark-themed, side-panel-sized browser over the knowledge graph.

Layout: header (title + "Sync Courses") → stats ribbon (six counts from `getGraphStatistics`) → course selector + module filter → course header with "Refresh Course" → module tree (collapsible, items listed under each) → "Pages" and "Files not in a module" sections → a right-hand detail panel for the selected node.

Data loading:
- On mount: statistics, courses (`exploreGraph({entity_type:'courses'})`), all tracked documents (`getFilesList()`); selects the first course.
- On course change: `exploreGraph({entity_type:'full_hierarchy'})` (with items) and `exploreGraph({entity_type:'pages', limit:200})`.
- On node selection: if the node maps to a document (`indexTargetFor`), loads its chunks with `getFileChunks`.

Actions:
- **Sync Courses** → `ensureCollection('courses', {}, { settings, refresh: true })` then reload.
- **Refresh Course** → `ensureCollections(['modules','assignments','files','pages'], { courseId }, { settings, refresh: true })` in series; the status pill summarizes which were updated, already current, unavailable in this course, or failed. Then reload the tree.
- **Index for search** (detail panel, when the node is a file/page/assignment) → `indexDocumentJustInTime(target, settings)` then refresh files/stats/chunks.

`indexTargetFor(node, courseId)` is the small adapter that turns any tree/list node (module item, page row, assignment row, loose file row) into the `{docId, IndexTarget}` pair the indexing pipeline needs; it builds doc ids with `docIdFor()` from `db/rag.ts`, the same function the tools and indexing use.

Status messages (`syncStatusMsg`) are transient (4 s) and shared by all actions; `isSyncing` disables both sync buttons while any sync runs.

## Navigation

Tabs plus the chat list. Chat rows show title and last-updated date; delete is revealed on hover. "New Chat" creates an empty chat immediately (it is also created implicitly if the user sends a message with no active chat).

## Styling notes

- Tailwind v4 via `@import "tailwindcss"` in `index.css`; typography plugin for Markdown.
- The side panel is narrow (often ~400 px). Components use `min-w-0`, `truncate`, and responsive `sm:`/`md:` breakpoints to stay usable; the Graph Explorer hides its subtitle and badge below `md`.
- `App.css` carries a `animate-fade-in` keyframe used by chat bubbles and status pills.
